# ideas

Открытая база идей и гипотез. Источник истины для личного Zettelkasten Ишаяу.

Цель репозитория не просто хранить тексты, а поддерживать сеть атомарных идей, в которой новые мысли сопоставляются со старыми и могут порождать новые связи, обобщения, контрпримеры и вопросы.

## Структура

- `00 - Карта/` — обзорные карты.
- `10 - Идеи/` — атомарные идеи: гипотезы, принципы, модели, аналогии, иллюстрации.
- `20 - Вопросы/` — самостоятельные открытые вопросы.
- `90 - Источники/` — сведения об исходных материалах, когда они содержательно нужны.

## Правила ведения

1. Одна заметка должна выражать одну самостоятельную мысль. Не дробить искусственно.
2. Сохранять эпистемический статус в YAML: `fact`, `observation`, `hypothesis`, `principle`, `model`, `analogy`, `question`, `illustration` и т.п.
3. Новую мысль перед сохранением сопоставлять с существующей базой не только по словам и теме, но по причинным механизмам, логической структуре, ограничениям, противоречиям и междисциплинарным аналогиям.
4. Фиксировать только содержательные связи через `[[wiki-links]]`.
5. Если сопоставление рождает самостоятельное новое обобщение, следствие, контрпример, противоречие или вопрос, оно может стать отдельной заметкой.
6. По умолчанию хранить саму идею, необходимые аргументы, возражения и связи, а не личную историю её возникновения. Контекст происхождения нужен лишь когда он необходим для понимания, проверки или иллюстрации.
7. Не превращать рабочие гипотезы в установленные факты.

## Открытость

Репозиторий публичен намеренно. Свободное использование и развитие идей другими людьми приветствуется. Дополнения, критика, ссылки на исследования и новые связи можно предлагать через issues и pull requests.
